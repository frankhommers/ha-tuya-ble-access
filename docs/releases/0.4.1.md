# 0.4.1 — Choose a finger when enrolling

Fingerprint enrollment in the access manager now asks which finger: thumb,
index, middle, ring or pinky on either hand. The choice is saved separately from
the label and person and appears underneath the access type in the list. Existing
fingerprints remain unchanged; older records do not gain a guessed finger.

While enrollment runs, the page explains how to follow the lock's finger-scan
prompts. A failed enrollment now shows a readable message and the device's error
code instead of a raw protocol dictionary.

The reported device error 0x01 means generic enrollment failure in Tuya's SDK and
panel. This update does not claim to fix its unknown underlying hardware cause.
Finger selection is local descriptive metadata and does not change the enrollment
command sent to the lock.

Update through HACS and restart Home Assistant. No reset or re-pairing is needed.
