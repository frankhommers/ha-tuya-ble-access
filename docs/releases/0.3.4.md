# 0.3.4 — Pause and resume temporary PINs

Adds admin-only Home Assistant actions `tuya_ble_access.pause_temp_password`
and `tuya_ble_access.resume_temp_password` for HA-created temporary PINs on the
verified K3 BLE PRO 2 Keybox profile (`ba2qk177`). Select the lock device and
supply the `password_id` returned by creation or `list_credentials`.

Pause disables all allowed weekdays without changing the PIN or its original
start/end dates. Resume restores its original validity; expired PINs cannot be
revived. No automatic resume is scheduled. The credential list reports
`active`, `paused`, or `unknown`; ambiguous Bluetooth outcomes remain unknown
and can be retried. State is persisted across Home Assistant restarts.

Physical validation on the Keybox confirmed that the same test PIN works,
is rejected while paused, and works again after resume. Keybox reboot and
day-rollover persistence remain untested. These actions do not support ordinary
PINs, cards, fingerprints, or other product profiles.

Install through HACS and restart Home Assistant to load the new actions.
Validation: automated suite, deterministic ZIP verification and secret scans.
